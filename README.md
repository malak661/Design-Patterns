# Design Patterns

Design patterns implemented in TypeScript — one pattern a day.

Each pattern lives in its own folder with a `main.ts` that demonstrates it.

## Patterns

| # | Pattern | Example |
|---|---------|---------|
| 1 | [Observer](./Observer) | A product price change notifies subscribers |
| 2 | [Strategy](./Strategy) | A shopping cart paying by cash, card or wallet |

## Running

```bash
npx ts-node Observer/main.ts
```

```bash
npx ts-node Strategy/main.ts
```
